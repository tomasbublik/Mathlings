# P18 — Lokalizace (i18n) + výběr jazyka

**Tier:** Opus 4.7 · **Wave:** 5 · **Deps:** všechny existující UI scény (P8a/b/c, P10, P13, P16 pokud je hotov, P17).

## Scope

Nahradit všechny hardcoded UI stringy (česká slovní literály v `.gd` a `.tscn`) překladovými klíči, přidat 12 jazykových mutací (English jako default, Czech, + 10 nejmluvenějších světových jazyků), implementovat:

1. **First-run language picker.** Při prvním spuštění (chybí `general/locale` v settings) zobraz `scenes/locale/locale_picker.tscn` se seznamem dostupných jazyků. Po volbě nastavit `general/locale` a pokračovat na Main Menu.
2. **Language switcher v Settings.** Sekce „Jazyk / Language" s dropdownem nebo radio group; změna okamžitě reloaduje scénu.
3. **RTL podpora pro arabštinu a urdštinu** (Godot natively přes `TranslationServer.get_language()` + `Control.layout_direction = LAYOUT_DIRECTION_RTL`).

**Změna defaultu:** DESIGN.md říká `locale = "cs_CZ"`. Tento WP overruluje na `locale = "en"`. DESIGN je třeba aktualizovat.

**Mimo scope:** překlad zvuků/grafik (jen textové stringy); pluralizace nad rámec Godot defaults.

## Files to create / modify

- `assets/translations/strings.csv` — master CSV s klíči a sloupci per locale.
- `assets/translations/strings.{locale}.translation` — auto-generované Godot importem (commitnout pro deterministic build).
- `project.godot` — registrace překladů + výchozí locale.
- `scenes/locale/locale_picker.tscn` + `.gd` — first-run obrazovka.
- `scenes/settings/settings.tscn` + `.gd` — sekce Jazyk.
- **Všechny ostatní scény + scripty** — náhrada literálů za `tr("KEY")`.
- `scripts/ui/locale_catalog.gd` — `class_name LocaleCatalog`, seznam podporovaných locales + native názvy.
- `tests/unit/test_translations.gd` — kontrola, že všechny klíče existují ve všech locales (žádný „##KEY_NAME").

## Klíčový schema

Konvence: `SCREEN_SECTION_LABEL`. Příklady:

```
MAIN_MENU_TITLE,Mathlings,Mathlings,Mathlings,...
MAIN_MENU_PLAY_BUTTON,Play!,HRÁT!,玩!,खेलें!,...
MAIN_MENU_STATS_BUTTON,Statistics,Statistiky,...
SETTINGS_DURATION_LABEL,Round duration,Délka kola,...
SETTINGS_LANGUAGE_LABEL,Language,Jazyk,...
PARENT_GATE_QUESTION,How much is %d × %d?,Kolik je %d × %d?,...
SKILL_ADD_0_20,Addition up to 20,Sčítání do 20,...
RESULTS_TITLE_GOOD,Great job!,Super práce!,...
```

> Format strings (`%d`, `%s`) nesmí překladatel měnit — auditováno testem.

CSV header:

```
keys,en,cs,zh,hi,es,fr,ar,bn,ru,pt,ur,id
```

```gdscript
const SUPPORTED: Array[Dictionary] = [
    {"code": "en", "native": "English"},
    {"code": "cs", "native": "Čeština"},
    {"code": "zh", "native": "中文"},
    ...
]

const DEFAULT_LOCALE: String = "en"

static func is_rtl(code: String) -> bool
static func native_name(code: String) -> String
```

## Project setup

V `project.godot`:

```
[internationalization]
locale/translations=PackedStringArray("res://assets/translations/strings.en.translation",
                                      "res://assets/translations/strings.cs.translation", ...)
locale/fallback="en"
```

Při startu `_ready()` SettingsStore (nebo nový `LocaleService` autoload):

```gdscript
var locale: String = SettingsStore.get_value("general/locale", "")
if locale == "":
    return  # první start, picker se zobrazí
TranslationServer.set_locale(locale)
get_tree().root.layout_direction = (
    Control.LAYOUT_DIRECTION_RTL if LocaleCatalog.is_rtl(locale)
    else Control.LAYOUT_DIRECTION_LTR
)
```

## Změny ve scénách

Každý `Label.text`, `Button.text`, `LineEdit.placeholder_text` který obsahuje viditelný literál → atributu se nastaví `text_key` (přes `auto_translate_mode` v Godot 4.6 stačí mít text v podobě `MAIN_MENU_PLAY_BUTTON` a Godot ho vyřeší přes TranslationServer).

Alternativa pro dynamicky generované labely (`"Sezení: %d" % sessions`) — použít `tr("STATS_SESSIONS_FORMAT") % sessions` se zvlášť přeloženým formátem.

## Definition of Done

1. `assets/translations/strings.csv` obsahuje všech ≥ ~80 UI klíčů × 12 locales.
2. Žádný `.tscn` nebo `.gd` neobsahuje literální české / anglické řetězce viditelné v UI (ignoruj debug logy a `push_warning`).
3. Při prvním startu se zobrazí language picker; po volbě se Main Menu zobrazí v daném jazyce.
4. Settings → Jazyk → změna na arabštinu reloaduje scénu, layout je RTL.
5. Kontrolní test: spustit hru v `cs`, dohrát kolo, otevřít Results → veškerý text je česky.
6. `test_translations.gd` všechny průchozí.
7. DESIGN.md §6.3 aktualizováno: `locale` default = `"en"` (komentář o důvodu změny).

## Otevřené otázky

- **Strojový překlad.** Spec očekává „pre-translated" CSV; reálně AI agent texty přeloží sám (s poznámkou, že u nestandardních locales je vhodný native review). Pokud uživatel preferuje jen kostru se stub `[TODO]`, zaznamenat tady.

## Implementation log

- `scripts/ui/locale_catalog.gd` (`class_name LocaleCatalog`) — single source of truth pro 12 locales. `SUPPORTED` má `{code, native, rtl}`; helpery `is_supported`, `is_rtl`, `native_name`, `all_codes`. RTL flag = jen `ar` + `ur`.
- `scripts/autoload/locale_service.gd` (autoload, registrován hned za SettingsStore). V `_ready` načte `general/locale` přes SettingsStore, aplikuje na `TranslationServer.set_locale`, prochází descendants root scény a nastaví `layout_direction` (LTR/RTL). Poslouchá `EventBus.settings_changed` a re-aplikuje při změně.
- `assets/translations/strings.csv` — 91 klíčů × 12 jazyků. Pokrývá: Main Menu, Game HUD, Settings, Results, Stats, Parent Gate, Profile picker/manager, Rules, Locale picker, skill_keys (16) + theme labels (3). Čeština + 11 dalších locales (EN, ZH, HI, ES, FR, AR, BN, RU, PT, UR, ID).
- `project.godot`: `[internationalization] locale/translations` registruje všech 12 `.translation` souborů, `locale/fallback="en"`. Godot importer regeneruje `.translation` soubory z CSV automaticky.
- `SettingsStore`: výchozí `general/locale` přepnut z `cs_CZ` na `en` (DESIGN.md §6.3 změna). Přidán nový klíč `general/locale_chosen` (boolean) — flag, že first-run picker proběhl.
- `scenes/locale/locale_picker.tscn` + `.gd` — vstupní scéna pro první spuštění. Renderuje 12 tlačítek s native názvem každého jazyka. Po kliknutí persistuje volbu, aplikuje locale a forwarduje na ProfilePicker (nebo Main Menu, pokud profil už existuje).
- Main Menu boot flow: `_ready()` nejprve zkontroluje `general/locale_chosen` flag → pokud chybí, redirect na LocalePicker. Pak ProfileService.ensure_ready() → ProfilePicker. Pak normální flow + voláno `_apply_translations()` které pumpuje text všech tlačítek přes `tr()`. Listener na EventBus.settings_changed re-aplikuje při změně jazyka v Settings.
- `SkillLabels` — kompletně přepsán z hardcoded Czech Dictionary na `tr(SKILL_<KEY>)` lookup, `TRANSLATION_KEYS` const drží mapping (skill_key → CSV key).
- `scenes/game/game.gd` HUD strings (score, streak, timer, countdown GO) prošly přes `tr()`.

### Známá omezení / nedoladěno

- **Rules screen body** stále generuje češtinu z `ScoringRules.to_human_readable_text()` — i18n tohoto by vyžadoval zásadní refactor na format-string template per klíč. CSV má pro to připravený `RULES_TITLE`, body čeká na navazující WP. Open question dokumentuje.
- **Settings, Stats, Results, Parent Gate, Profile picker/manager** mají v CSV připravené klíče, ale jejich .gd a .tscn ještě nepoužívají `tr()` u všech literálů. UI displeje stále zobrazí česky/anglicky podle původního kódu — překlady jsou „kostra připravena, refaktor čeká". Kritické HUD stringy (Main Menu, Game) jsou hotové.
- **Reálná kvalita překladů** v některých jazycích (BN, HI, AR, UR) by si zasloužila native review. Test_translations.gd hlídá kompletnost a format-specifier konzistenci, ne sémantickou kvalitu.

### Testy (3 soubory)

- `test_locale_catalog.gd` (8 testů) — DEFAULT_LOCALE pravdivost, struktura SUPPORTED, RTL flag pokrytí, defenzivní fallbacks.
- `test_translations.gd` (4 testy) — CSV header == LocaleCatalog.all_codes(), žádný řádek s prázdnou buňkou, format-specifier counts (`%d`, `%s`) match napříč locales (chyt í drop'nuté `%d` v překladu).
- `test_skill_labels.gd` (přepsán) — TRANSLATION_KEYS pokrývají všechny `ProblemGenerator.supported_skills()`, label není raw key, naming convention `SKILL_*`.
